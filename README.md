# 2D OpenGL Animated Transportation Scene

A 2D animated transportation environment developed using C++ OpenGL and GLUT.

## Features

- Animated cars
- Moving train
- Flying airplane
- Moving clouds
- Day and night environment
- 2D object modeling using OpenGL primitives

## Technologies Used

- C++
- OpenGL
- GLUT

## Concepts Implemented

- 2D transformation
- Translation
- Polygon drawing
- Animation
- User interaction

## Controls

- Keyboard controls for object movement
- Animation based on transformation functions

## How to Run

1. Install OpenGL and GLUT libraries.
2. Open the project in a C++ IDE.
3. Compile and run the source file.
4. Enjoy the animated transportation scene.
